# Dale Yang

字節跳動 **Agent 工程師**。主要關注大型語言模型周邊的執行系統：
工具調用、知識檢索、評測、可觀測性與人工控制。

我更在意系統能否完成真實任務，以及每一步是否留下足夠的證據供人理解與追溯。
