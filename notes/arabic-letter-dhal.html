05.12 / Arabic letter / ZH + AR

ذ：扎勒（浊齿间音）

用齿间持续摩擦和声带振动发出 /ð/。

ذ ذَال
字母 09 / dhāl / dh 扎勒（浊齿间音）

浊齿间摩擦音，形体是 د 上方加一点。

Listen / Web Speech ذ 的字母名与基础音节

先听字母名，再听同一辅音与 Fatha、Kasra、Damma 的组合。重复播放用于建立口型和时长记忆。

点击播放后，浏览器会优先使用 ar-SA 标准阿拉伯语音色。

基础属性

项目 内容
字母 ذ
阿拉伯语名称 ذَال
转写 dhāl / dh
IPA /ð/
发音部位 上下门齿之间
发音方式 浊摩擦音
声带 声带振动
连写类型 右向连接字母：可接右侧先写字母，但会切断与左侧后写字母的连接。

四种书写形态

独立形 ذ 单独出现或两侧都不连接
词首形 ذ 连接左侧后写字母
词中形 ـذ 两侧连接时的形态
词尾形 ـذ 连接右侧先写字母

浏览器会根据相邻字母的连接属性自动选择上下文形态。表格使用延长线展示连接端，真正输入时不要把延长线当作字母的一部分。

ذ 属于六个基础“断连字母”之一。它出现后，左侧下一个字母必须重新起笔。

发音口型与动作

舌尖轻伸到齿间，持续送气，同时让声带振动。舌尖不要缩回齿龈后方。

气流方式： 连续摩擦，喉部能感到振动。

练习时按以下顺序：

  1. 先不带元音，只建立发音部位；
  2. 加 Fatha 读 ذَ；
  3. 保持辅音不变，改读 ذِ、ذُ；
  4. 用手摸喉部，核对声带是否应当振动；
  5. 录下自己的声音，与页面朗读逐次对比。

中文近似音：只能定位，不能替代

接近英语 this 的 th；普通话没有对应音。

中文近似音只帮助第一次找到大致口型。阿拉伯语中的齿间音、咽音、小舌音和厚音在普通话里没有等价项，最终必须以发音部位和气流为准。

绝对不要这样读

禁止读成 /z/、/d/ 或汉语“日”；不要省略齿间舌位。

如果页面语音与中文近似提示冲突，应优先遵循 IPA、口腔动作和阿拉伯语音色，不要把汉字注音当成标准答案。

写法与识别

先写 د 的短弧主干，再在上方补一个点；保持不向左连接。

书写时遵循从右向左的整体方向，先完成主干，再补点。点不是装饰，点的数量和位置直接决定字母身份。

相似字母区分

与 ث 对比：两者都在齿间，但 ث /θ/ 清、ذ /ð/ 浊；与 د 只差一点。

建议把相似字母放在同一行反复辨认，而不是只背单个字母：

ذ　ذ　ـذ　ـذ

新手常见误区

  • 舌尖缩回而读成 ز。
  • 没有声带振动而读成 ث。
  • 向左错误连写。

当课检查

  • 能从四种位置形态中认出 ذ；
  • 能说出它是否会切断左侧连接；
  • 能按正确发音部位读出 /ð/；
  • 能连续读出 ذَ　ذِ　ذُ 而不改变辅音；
  • 能指出最容易混淆的字母及区别依据。
