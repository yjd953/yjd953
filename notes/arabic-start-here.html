05.01 / Learning path / ZH + AR

零基础应该怎样开始学阿拉伯字母？

先建立从右向左、字母骨架、点位、连写与音标的整体地图，再进入逐字训练。

阿拉伯语不是“把 28 个符号背完”就结束。零基础阶段需要同时建立四条线：

  1. 看得见：认出独立、词首、词中、词尾形；
  2. 连得上：知道哪些字母会切断后续连接；
  3. 发得准：按口腔部位、声带和气流发音；
  4. 读得出：把辅音和 Fatha、Kasra、Damma 等基础音标组合。
Audio check 先确认浏览器可以朗读阿拉伯语

页面只在你点击按钮后发音。网站不保存录音，也不需要麦克风；朗读由浏览器或操作系统提供的阿拉伯语音色完成。

点击播放后，浏览器会优先使用 ar-SA 标准阿拉伯语音色。

本板块学什么

本板块严格停留在零基础字母与发音层：

  • 28 个基础字母；
  • 每个字母的名称、IPA、口腔位置和气流；
  • 独立、词首、词中、词尾形；
  • 六个基础断连字母；
  • Fatha、Kasra、Damma；
  • Sukun、Shadda、Tanwin；
  • 三组长元音；
  • Hamza 与 Maddah。

不展开词汇、句子、语法、方言和复杂诵读规则。示范组合仅用于发音训练，不要求记忆词义。

推荐学习顺序

第一轮：只认骨架与点

先看字母形状家族：

ب ت ث　ج ح خ　د ذ　ر ز　س ش　ص ض　ط ظ　ع غ　ف ق

同一骨架依靠点的数量和位置区分。第一轮不要急着追求书写速度。

第二轮：加入发音部位

把字母放回口腔地图：

双唇 → 唇齿 → 齿间/齿龈 → 硬腭 → 软腭/小舌 → 咽腔 → 声门

遇到普通话没有的音，不背汉字谐音，直接记“舌头在哪里、气流怎么走、声带是否振动”。

第三轮：学习连接

重点先背六个不向左连接的字母：

ا　د　ذ　ر　ز　و

看见它们，就知道左侧下一个字母要重新起笔。

第四轮：加入基础音标

使用同一个字母练习：

بَ　بِ　بُ　بْ　بَّ　بَا　بِي　بُو

先保持辅音不变，再控制短音、零元音、双辅音和长元音。

每课怎样练

  1. 看大字形 5 秒，指出点位；
  2. 点击字母名播放一次；
  3. 不看中文提示复读 3 次；
  4. 对照四种形态手写一行；
  5. 播放三短音并跟读；
  6. 说出一个最容易混淆的字母；
  7. 第二天先复习，再进入下一课。

关于网页朗读

本站使用浏览器 Web Speech API，优先选择设备中的 ar-SA 音色，其次选择其他 ar-* 阿拉伯语音色。实际音色由浏览器和操作系统提供，不同设备的音质、方言色彩和可用音色可能不同。页面会显示实际选中的音色；如果设备没有阿拉伯语音色，仍会提交 ar-SA 语言标签让浏览器选择后备语音，但不能替代真人教师的纠音。
