# Dale Yang

مهندس Agent در **ByteDance**. تمرکز من بر زیرساخت پیرامون مدل‌های زبانی است:
استفاده از ابزارها، بازیابی دانش، ارزیابی، مشاهده‌پذیری و کنترل انسانی.

برای من مهم است که سیستم‌ها کار واقعی را به پایان برسانند و برای توضیح و
بازبینی هر مرحله، شواهد کافی باقی بگذارند.
