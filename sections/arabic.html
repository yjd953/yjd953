字母 01–07

07 notes
04 Arabic letter / ZH + AR / alif / ā / /aː/；字母名 /ʔalif/ ا：艾利夫 认识只向右连接的 ا，并掌握它作为长元音 /aː/ 载体的核心作用。 ↗ 05 Arabic letter / ZH + AR / bāʾ / b / /b/ ب：巴 用双唇闭合与声带振动发出 /b/，并通过点位区分 ب、ت、ث。 ↗ 06 Arabic letter / ZH + AR / tāʾ / t / /t/ ت：塔 掌握不送气的清 /t/，并用上方双点准确识别 ت。 ↗ 07 Arabic letter / ZH + AR / thāʾ / th / /θ/ ث：萨（齿间音） 把舌尖置于齿间发 /θ/，避免退化为普通的 /s/。 ↗ 08 Arabic letter / ZH + AR / jīm / j / /d͡ʒ/（现代标准阿拉伯语教学音） ج：吉姆 用“先闭塞、后摩擦”的连续动作发出标准 /d͡ʒ/。 ↗ 09 Arabic letter / ZH + AR / ḥāʾ / ḥ / /ħ/ ح：哈（清咽音） 从咽腔深处建立持续清摩擦，严格区分 ح /ħ/ 与 ه /h/。 ↗ 10 Arabic letter / ZH + AR / khāʾ / kh / /x/ خ：赫 让舌后部与软腭形成持续摩擦，发出无声带振动的 /x/。 ↗

字母 08–14

07 notes
11 Arabic letter / ZH + AR / dāl / d / /d/ د：达勒 掌握浊 /d/ 与只向右连接的书写行为。 ↗ 12 Arabic letter / ZH + AR / dhāl / dh / /ð/ ذ：扎勒（浊齿间音） 用齿间持续摩擦和声带振动发出 /ð/。 ↗ 13 Arabic letter / ZH + AR / rāʾ / r / /r/（闪音或短颤音） ر：拉 放松舌尖形成闪音/短颤音，并牢记 ر 不向左连接。 ↗ 14 Arabic letter / ZH + AR / zāy / z / /z/ ز：宰 持续发出带声的 /z/，用上方一点区分 ر。 ↗ 15 Arabic letter / ZH + AR / sīn / s / /s/ س：辛 以清晰中央气流发 /s/，并保持口腔前部的薄音音色。 ↗ 16 Arabic letter / ZH + AR / shīn / sh / /ʃ/ ش：希恩 在后齿龈形成宽摩擦，发出不卷舌的 /ʃ/。 ↗ 17 Arabic letter / ZH + AR / ṣād / ṣ / /sˤ/ ص：萨德（厚音） 在 /s/ 基础上加入舌根后缩，建立真正的厚音 /sˤ/。 ↗

字母 15–21

07 notes
18 Arabic letter / ZH + AR / ḍād / ḍ / /dˤ/ ض：达德（厚音） 把浊 /d/ 与舌根后缩结合，发出厚重的 /dˤ/。 ↗ 19 Arabic letter / ZH + AR / ṭāʾ / ṭ / /tˤ/ ط：塔（厚音） 保持不送气闭塞，并用舌根后缩形成厚音 /tˤ/。 ↗ 20 Arabic letter / ZH + AR / ẓāʾ / ẓ / /ðˤ/（部分现代口语实现为 /zˤ/） ظ：扎（厚齿间音） 结合齿间摩擦、声带振动与舌根后缩，发出 /ðˤ/。 ↗ 21 Arabic letter / ZH + AR / ʿayn / ʿ / /ʕ/ ع：阿因 通过有声咽腔收窄建立 /ʕ/，避免省略或误读为声门断音。 ↗ 22 Arabic letter / ZH + AR / ghayn / gh / /ɣ/（可有小舌化实现） غ：盖因 在舌后持续摩擦并加入声带振动，形成 /ɣ/。 ↗ 23 Arabic letter / ZH + AR / fāʾ / f / /f/ ف：法 保持下唇与上齿的窄缝，发出连续清晰的 /f/。 ↗ 24 Arabic letter / ZH + AR / qāf / q / /q/ ق：嘎夫（小舌塞音） 把 /k/ 的闭塞位置后移到小舌区域，建立清塞音 /q/。 ↗

字母 22–28

07 notes
25 Arabic letter / ZH + AR / kāf / k / /k/ ك：卡夫 在软腭形成短促清塞音 /k/，严格区分更靠后的 ق。 ↗ 26 Arabic letter / ZH + AR / lām / l / /l/ ل：拉姆 让中央闭合、两侧通气，形成清楚的齿龈边音 /l/。 ↗ 27 Arabic letter / ZH + AR / mīm / m / /m/ م：米姆 闭合双唇并让气流走鼻腔，发出稳定浊鼻音 /m/。 ↗ 28 Arabic letter / ZH + AR / nūn / n / /n/ ن：努恩 用舌尖齿龈闭合与鼻腔气流发 /n/，并掌握共享骨架的点位。 ↗ 29 Arabic letter / ZH + AR / hāʾ / h / /h/ ه：哈（声门音） 用轻柔声门气流发 /h/，不要把它读成深咽音 ح。 ↗ 30 Arabic letter / ZH + AR / wāw / w, ū / /w/；长元音 /uː/ و：瓦乌 区分辅音 /w/ 与长元音 /uː/，并牢记 و 不向左连接。 ↗ 31 Arabic letter / ZH + AR / yāʾ / y, ī / /j/；长元音 /iː/ ي：雅 区分辅音 /j/ 与长元音 /iː/，用下方双点识别 ي。 ↗

08 notes
32 Arabic phonetics / ZH + AR / َ / /a/ Fatha：短 /a/ 认识写在字母上方的 Fatha，并建立短促稳定的 /a/。 ↗ 33 Arabic phonetics / ZH + AR / ِ / /i/ Kasra：短 /i/ 认识字母下方的 Kasra，并区分短 /i/ 与长 /iː/。 ↗ 34 Arabic phonetics / ZH + AR / ُ / /u/ Damma：短 /u/ 通过圆唇建立短 /u/，避免滑向 /ou/ 或拉成长音。 ↗ 35 Arabic phonetics / ZH + AR / ْ / 辅音后不带短元音 Sukun：无后续元音 看见 Sukun 就在辅音后收住，不添加任何短元音。 ↗ 36 Arabic phonetics / ZH + AR / ّ / 辅音长音 / gemination Shadda：辅音加倍 把辅音真正延长为双辅音，而不是加重音量或重复字母名。 ↗ 37 Arabic phonetics / ZH + AR / ً ٍ ٌ / /an/、/in/、/un/ Tanwin：-an / -in / -un 把双短音符号读成短元音加 /n/，暂不进入语法规则。 ↗ 38 Arabic phonetics / ZH + AR / ا و ي / /aː/、/uː/、/iː/ 三组长元音 用稳定口型和两拍时长区分 /aː/、/uː/、/iː/。 ↗ 39 Arabic phonetics / ZH + AR / ء أ إ ؤ ئ آ / /ʔ/；آ 常表示 /ʔaː/ Hamza 与 Maddah 掌握声门塞音 /ʔ/ 及其字座，并区分短 أَ 与长 آ。 ↗
